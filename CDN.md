# CDN Dependencies

This project uses the following external libraries, imported via ESM from `esm.sh`:

*   **idb** (v7.1.1): IndexedDB wrapper for local data storage.
    *   URL: `https://esm.sh/idb@7.1.1`
*   **peerjs** (v1.5.4): Peer-to-peer networking for sync.
    *   URL: `https://esm.sh/peerjs@1.5.4?bundle-deps`
*   **qrcode** (v1.5.3): QR code generation for pairing devices.
    *   URL: `https://esm.sh/qrcode@1.5.3`
*   **jszip** (v3.10.1): Create, read and edit .zip files.
    *   URL: `https://esm.sh/jszip@3.10.1`

## Removed
*   **sortablejs**: Replaced with custom native Drag and Drop implementation.
